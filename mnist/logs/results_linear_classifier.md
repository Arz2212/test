## 1. Архитектурные изменения и перевод спайков в непрерывный сигнал

В исходном `mnist_solver.py` выходной слой состоял из матрицы `C3 (1000 × 10)`, спайковых нейронов `lif_out`, экспоненциального следа `tr_out` и локального дельта-правила `C3.grad = -(z2.T @ dmu)`.

В `mnist_solver_linear.py` спайковый выходной слой полностью удалён и заменён на классический линейный классификатор **`torch.nn.Linear`**, обучаемый кросс-энтропией (`F.cross_entropy`) и `AdamW` с косинусным расписанием шага обучения. Скрытые слои (`W1, M1, V2y, W2, M2, V3y`) по-прежнему обучаются локально по правилу **CSDP** с хаб-модуляцией без обратного распространения ошибки в SNN.

### Варианты перевода спайков в обычный сигнал (`decode_spikes`)
За $T = 50$ тактов симуляции накапливается вектор количества спайков нейронов скрытого слоя $c = \sum_{t=1}^{T} z(t)$. Протестировано **9 способов декодирования**:

1. **`count`**: $c = \sum_{t=1}^T z(t)$ — сырое количество спайков за окно $T$ *(прямая реализация идеи из обсуждения с научным руководителем)*.
2. **`rate`**: $c / T \in [0, 1]$ — средняя частота спайкования.
3. **`l2_count`**: $c / \|c\|_2$ — L2-нормированный вектор числа спайков (убирает глобальный дрейф амплитуды активности от примера к примеру).
4. **`sqrt`**: $\sqrt{c}$ — преобразование Анскомба (стабилизация дисперсии для пуассоновского потока спайков, у которого дисперсия равна среднему).
5. **`l2_sqrt`** *(по умолчанию в `mnist_solver_linear.py`)*: $\sqrt{c} / \|\sqrt{c}\|_2$ — представление Хеллингера / Бхаттачарьи (сочетает стабилизацию дисперсии редких и частых спайков с единичной L2-нормой).
6. **`zscore`**: $(c - \mu_c) / (\sigma_c + \varepsilon)$ — стандартизация вектора спайков внутри каждого объекта.
7. **`log1p`**: $\ln(1 + c)$ — сублинейное логарифмическое сжатие (закон Вебера—Фехнера).
8. **`mean_trace`**: $\frac{1}{T}\sum_{t=1}^T \text{tr}(t)$ — средний синаптический след.
9. **`trace`**: $\text{tr}(T)$ — финальное значение экспоненциального следа ($\tau_{\text{tr}} = 13$).

## 2. Ключевой эффект режима обучения классификатора (`pos` vs `clean`)

При обучении скрытых слоёв CSDP в положительной фазе (`pos`) в нейроны подаётся истинная метка `y` через обратные связи `y @ V2y` и `y @ V3y`, тогда как на тесте (`evaluate`) метка обнуляется (`y = 0`).

Эксперимент показал критическую разницу:
- Если обучать `nn.Linear` на спайках положительной фазы (**`pos`, `y = yb`**), линейный классификатор мгновенно переобучается на подсказку от `V2y/V3y` (**`Train Acc = 0.9990`**, но тест проседает до **`0.9464–0.9564`** на `z2` и **`0.9397`** на `z1+z2`).
- Если подавать в `nn.Linear` спайки из режима без подсказки метки (**`clean`, `y = 0`**, совпадающего с режимом инференса), переобучение исчезает, а тестовая точность вырастает до **`0.9627`** на `z2` (`1000 → 10`) и **`0.9698`** на `z1+z2` (`6000 → 10`).

| Способ декодирования (`z2: 1000 → 10`) | `pos` (`y=yb`) Best Test | `pos` Ep 12 Train | **`clean` (`y=0`) Best Test** | `clean` Ep 12 Train |
| :--- | :---: | :---: | :---: | :---: |
| `count` (сырое число спайков) | `0.9464` | `0.9990` | **`0.9577`** | `0.9758` |
| `rate` (`count / T`) | `0.9530` | `0.9991` | **`0.9576`** | `0.9719` |
| `l2_count` (`count / \|\|count\|\|_2`) | `0.9466` | `0.9990` | **`0.9602`** | `0.9756` |
| `zscore` (стандартизация) | `0.9564` | `0.9992` | **`0.9600`** | `0.9776` |
| `log1p` (`ln(1 + count)`) | `0.9557` | `0.9990` | **`0.9619`** | `0.9765` |
| `l2_sqrt` (`sqrt(count)` + L2) | `0.9538` | `0.9990` | **`0.9627`** | `0.9785` |
| `mean_trace` | `0.9519` | `0.9991` | **`0.9551`** | `0.9717` |
| `trace` (финальный след) | `0.9535` | `0.9990` | **`0.9537`** | `0.9686` |

## 4. Примеры запуска

```bash
# 1. Конфигурация по умолчанию (строгая замена последнего слоя 1000 -> 10, l2_sqrt, Best = 0.9627):
python3 mnist_solver_linear.py --epochs 30 --device cuda

# 2. Базовый вариант (сырое количество спайков z2 -> Linear(1000, 10), Best = 0.9573):
python3 mnist_solver_linear.py --epochs 30 --device cuda \
    --spike-mode count --lr-cls 0.001 --wd-cls 0.001 --cls-dropout 0.1 --cls-steps 1

# 3. Линейный классификатор по спайкам обоих скрытых слоёв z1+z2 (6000 -> 10, Best = 0.9698):
python3 mnist_solver_linear.py --epochs 30 --device cuda \
    --feat-source z1_z2 --spike-mode zscore --lr-cls 0.001 --wd-cls 0.001 --cls-dropout 0.15 --cls-steps 1
```
